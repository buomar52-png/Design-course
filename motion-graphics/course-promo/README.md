# إعلان الدورة — ستوري · القالب النهاري بدون مربعات · ٩:١٦ · ٥٣ ثانية

ستوري إعلاني بالقالب النهاري، بلا عنوان ولا ترقيم. الانتقال بين الشرائح **«مدّ ضوئي»**، وفي النهاية أيقونة المشاركة.

**تنوّع الشرائح:**
| النوع | الشرائح |
|---|---|
| **نصّية فقط** | «هل تودّ أن تصمّم: كاروسيل / عرضًا تقديميًّا / بأسلوبك وهويّتك؟»، «في هذه الدورة سنتعلّم»، «الأهمّ من كلّ ذلك» |
| **رسم توضيحي فقط** | بصمة إصبع ترسم نفسها (نتائج تعكس أسلوبك) · لوح تصوير يُطبَق ويبدأ الفيديو (الفيديوهات القصيرة) |
| **مزدوجة** | صفحة مكتوبة وساعة رملية · ٩ نتائج متطابقة تنبض معًا عند «متشابهة» · جوال بأشرطة ستوري تمتلئ · قائمة «كيف» بأيقونات · شريط أوامر يُكتب ثم يُرسل · قلم يكتب · بطاقات كاروسيل تنسحب · شريحة تُبنى من الصفر ثم يُعاد تصميمها · مفتاح يفتح مهارات جديدة · زر «سجّل اهتمامك» مع نقرة وموجات |

| الملف | الاستخدام |
|---|---|
| `output/course-promo-reel-voice.mp4` | **الفيديو النهائي مع الصوت** |
| `output/course-promo-reel.mp4` | بدون صوت |
| `index.html` | المصدر الحي، يُولَّد من `tools/build.py` |
| `audio/voice-clean.m4a` | الصوت بعد المعالجة والتنظيف |
| `audio/voice-original.m4a` | التسجيل الأصلي |
| `reels/transcript.md` | النص على الشاشة وسجل تعديلات الصوت |

## إعادة البناء
```bash
python3 tools/build.py
S=../../.claude/skills/carousel-to-reel/scripts
ffmpeg -i audio/voice-original.m4a -ac 1 -ar 48000 -af "$(cat tools/studio-chain.txt)" -c:a pcm_s16le /tmp/studio.wav
python3 $S/clean_voice.py /tmp/studio.wav tools/transcript.json audio --no-denoise --cut 52.30-62.52 --cut 65.86-68.58
node $S/render.js . --audio audio/voice-clean.m4a
```
