# تعلّم Claude في ٤ خطوات — القالب النهاري · ٩:١٦ · ٥٢ ثانية

ريل إعلاني لدورة «أساسيات Claude» بالقالب النهاري، بلا عنوان ولا ترقيم. الانتقال بين الشرائح **«مدّ ضوئي»**، وفي النهاية أيقونة المشاركة.
شرائح الخطوات الأربع فوقها **شريط تقدّم** يمتلئ خطوةً بعد خطوة.

| النوع | الشرائح |
|---|---|
| **نصّية فقط** | «أفضل طريقة لتعلّم Claude — ٤ خطوات» (رقم ضخم) · «التجربة، ثمّ التجربة، ثمّ التجربة» (كل مرة أكبر) · «ثمّ الخطوة الأهمّ» · «سواء كنتَ: معلّم / صانع محتوى / طالب / مدرّب» |
| **رسم توضيحي** | باب يُفتح على الضوء (مجال واسع للإبداع) · خط مستقيم بعرض الشاشة من نقطة «بلا تجربة» إلى نقطة «بالتجربة» |
| **مزدوجة** | أساس يُبنى مكعبًا مكعبًا · شعار Claude في المركز تدور حوله قدراته (كتابة، صور، رسوم بيانية، برمجة، فيديو) · عصا سحرية وبريق (ستنبهر) · بطاقة تتعدّل بالقلم الأحمر وتدور ثم تصير قالبًا معتمدًا · بطاقة الدورة · كاروسيل متصل: ثلاث شرائح متلاصقة وإطار جوال يتنقّل بينها · محرّر موشن جرافيك: معاينة وكائن يتحرك على مساره، وخط زمني بإطارات مفتاحية ومؤشر تشغيل · مجموعة شرائح تنفرد وتُبنى الشريحة الأمامية (عنوان، نص، رسم دائري) · قطعتا أحجية تلتحمان · لابتوب يُشطب ويظهر الآيباد والجوال · دبوس موقع وزر «سجّل اهتمامك» مع نقرة |

| الملف | الاستخدام |
|---|---|
| `output/claude-course-reel-voice.mp4` | **الفيديو النهائي مع الصوت** |
| `output/claude-course-reel.mp4` | بدون صوت |
| `index.html` | المصدر الحي، يُولَّد من `tools/build.py` |
| `audio/voice-clean.m4a` | الصوت بعد المعالجة والتنظيف |
| `audio/voice-original.m4a` | التسجيل الأصلي |
| `reels/transcript.md` | النص على الشاشة وسجل تعديلات الصوت |

## إعادة البناء
```bash
python3 tools/build.py
S=../../.claude/skills/carousel-to-reel/scripts
ffmpeg -i audio/voice-original.m4a -ac 1 -ar 48000 -af "$(cat tools/studio-chain.txt)" -c:a pcm_s16le /tmp/studio.wav
python3 $S/clean_voice.py /tmp/studio.wav tools/transcript.json audio --no-denoise --cut 52.58-57.38 --cut 60.30-62.10 --cut 48.50-49.72
node $S/render.js . --audio audio/voice-clean.m4a
```
