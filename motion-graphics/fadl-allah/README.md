# فضلٌ ورحمة — القالب النهاري بدون مربعات · ٩:١٦ · ٢٦ ثانية

ريل من تسجيل صوتي، بلا عنوان ولا ترقيم في الأعلى.
- ست شرائح، لكل منها أيقونة متحركة.
- **في الشريحة الخامسة تجتمع الأيقونات الأربع وتضيء معًا** على «فضلٌ ورحمةٌ».
- ينتهي الريل بآية الحجرات وقلب ينبض.
- الانتقال «مدّ ضوئي» بنسخة نهارية، ومستمر مع الكلام.

| الملف | الاستخدام |
|---|---|
| `output/fadl-allah-reel-voice.mp4` | **الفيديو النهائي مع الصوت** |
| `output/fadl-allah-reel.mp4` | بدون صوت |
| `index.html` | المصدر الحي، فيه زر 🔊. يُولَّد من `tools/build.py` |
| `audio/voice-clean.m4a` / `audio/voice-original.m4a` | الصوت بعد التنظيف / التسجيل الأصلي |
| `reels/` | الغلاف والتفريغ |

```bash
python3 tools/build.py
node ../../.claude/skills/carousel-to-reel/scripts/render.js . --audio audio/voice-clean.m4a
```
