# فضلٌ ورحمة — تجربة ستايل الكولاج (غير معتمدة كقالب)

نسخة تجريبية من ريل `fadl-allah` بنفس الصوت والتوقيت والألوان، بستايل كولاج ورقي:
- كل شريحة ورقة تنزلق وتستقر فوق كومة الأوراق، مع الكلام.
- الكلمات قصاصات ورق ممزّقة تُلصق لحظة نطقها، والكلمات المهمة على شرائط ورق ملوّنة.
- الأيقونات ملصقات بحافة بيضاء مثبّتة بشريط لاصق.
- الآيات على ورق دفتر ممزّق، والمرجع ختم.
- رسومات قلم يدوية، وحبيبات ورق، واهتزاز خفيف بأسلوب الإيقاف الحركي (Stop-motion).

| الملف | الاستخدام |
|---|---|
| `output/fadl-allah-collage-reel-voice.mp4` | الفيديو مع الصوت |
| `index.html` | المصدر، يُولَّد من `tools/build.py` (يعيد استخدام أيقونات `fadl-allah`) |
