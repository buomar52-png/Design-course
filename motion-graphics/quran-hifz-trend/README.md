# استحضر عند حفظ القرآن — ستايل «ليل ونهار» (٩:١٦، ٢٧ ثانية)

نسخة بستايل مختلف من ريل `quran-hifz`. النص والصوت والتوقيت نفسها، والتصميم جديد يمزج الليلي والنهاري.

| المشهد | الثيم |
|---|---|
| الخطّاف | 🌙 ليل |
| ١ خيركم من تعلم القرآن وعلمه | ☀️ نهار |
| ٢ كان خلقه القرآن | 🌙 ليل |
| ٣ ويكفي الإنسان شرفًا | ☀️ نهار |

## الأسلوب
- **انتقال دائري** ينفتح من أعلى الشاشة مع كل فكرة ويكشف الثيم التالي (بلا عنوان ولا ترقيم في الأعلى).
- **نص كاريوكي:** الكلمات تظهر باهتة، وتضيء كل كلمة لحظة نطقها (التوقيت من `audio/timing.json`).
- رقم ضخم مفرّغ (١، ٢، ٣) في الخلفية.
- بقع لونية ناعمة بدل الشبكة، وحبيبات فيلم خفيفة.
- بطاقة زجاجية، ووسوم على شكل كبسولات.
- أخضر ليموني مع أزرق الهوية.

## الملفات
| الملف | الاستخدام |
|---|---|
| `output/quran-hifz-trend-reel-voice.mp4` | **الفيديو النهائي مع الصوت** |
| `output/quran-hifz-trend-reel.mp4` | نفس الفيديو بدون صوت |
| `index.html` | المصدر الحي، فيه زر 🔊 للتشغيل مع الصوت |
| `reels/` | الغلاف، والترجمة، والتفريغ، ووصف المنشور |
