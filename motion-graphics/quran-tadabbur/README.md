# كتاب الله مختلف — القالب الليلي بدون مربعات · ٩:١٦ · ٥١ ثانية

**التصميم: القالب الليلي بدون مربعات، مع الشريحة الأولى والأخيرة بالنظام النهاري.** الانتقال بين المشاهد اسمه **«مدّ ضوئي»**:
- شريط ضوء ناعم **ينزل من أعلى الشاشة** مع أول كلمة في الفكرة التالية.
- المشهد السابق يذوب للأسفل خلفه، والمشهد التالي ينكشف تحته بحافة متدرّجة.
- الكلام متصل بين الشرائح بلا وقفات طويلة.
- الخلفية مساحة واحدة متصلة بلا قطع.
- ينتهي الريل بتقريب بطيء على الآية الأخيرة.

**أيقونات متحركة للأمثلة الثلاثة:**
- **حزين:** غيمة تمطر، ومع «فتستبشر» تطلع الشمس من خلفها.
- **ضائقة مالية:** محفظة تهتز، ومع «عوّضه الله» تخرج منها عملات ذهبية.
- **التباس بين الحق والباطل:** مفترق طريقين وعلامة استفهام، ومع «يجعل له مخرجًا» يضيء الطريق الصحيح.

ريل من تسجيل صوتي: النص على الشاشة بالفصحى، والصوت منظّف من التقطيع والتكرار، والآية الكريمة ﴿إِنَّ فِي ذَٰلِكَ لَذِكْرَىٰ…﴾ في آخره. تفاصيل التعديلات في `reels/transcript.md`.

| الملف | الاستخدام |
|---|---|
| `output/quran-tadabbur-reel-voice.mp4` | **الفيديو النهائي مع الصوت** |
| `output/quran-tadabbur-reel.mp4` | نفس الفيديو بدون صوت |
| `index.html` | المصدر الحي، فيه زر 🔊 للتشغيل مع الصوت. يُولَّد من `tools/build.py` |
| `audio/voice-clean.m4a` | الصوت بعد التنظيف والتعديلات |
| `audio/voice-original-v2.m4a` | التسجيل المعتمد (الأخير) |
| `audio/voice-original.m4a` | التسجيل الأول |
| `reels/transcript.md` | النص على الشاشة وسجل تعديلات الصوت |

## إعادة البناء والتصدير
```bash
python3 tools/build.py                                      # يولّد index.html من مواصفات المشاهد
S=../../.claude/skills/carousel-to-reel/scripts
node $S/render.js . --audio audio/voice-clean.m4a
```

### تنظيف الصوت (للإعادة)
```bash
python3 $S/clean_voice.py audio/voice-original-v2.m4a transcript.json audio \
  --cut 0.0-9.55 --cut 50.62-73.02 --protect 79.95-80.46 --protect 81.62-86.45
```
