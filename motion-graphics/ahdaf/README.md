# الأهداف — القالب النهاري بدون مربعات · ٩:١٦ · ٩١ ثانية

**التصميم: القالب النهاري بدون مربعات (القالب ٣)**، بلا عنوان ولا ترقيم. الانتقال بين المشاهد **«مدّ ضوئي»** متصل مع الكلام، وينتهي الريل بأيقونة المشاركة.

**أيقونات متحركة لكل فكرة:**
- تقويم: تضيء خانة اليوم ثم الشهر ثم السنة.
- مصباح يضيء عند «أمورًا أهمّ».
- هدف يصيبه سهم عند «رضا الله».
- محراب: يظهر القنديل عند «الفرائض» ويشعّ عند «النوافل».
- كتب تتراكم: حفظ القرآن، علوم الفقه، ثم سهم صاعد عند «مطالب عالية».
- شبكة تتفرّع عند «كبيرٌ ومتشعّب».
- مخطط دائري يتأرجح عند «السذاجة».
- قمع يمرّ منه نوع واحد من الأهداف.
- فانوس يضيء عند «مبادئ نبويّة».
- قطرات تملأ كوبًا عند «أدومها وإن قلّ».
- ميزان يتأرجح ثم يستقرّ عند «ما تطيقون».
- مصحف مع الآية ﴿لَا يُكَلِّفُ اللَّهُ نَفْسًا إِلَّا وُسْعَهَا﴾.
- «في التخفيف» يُشطب، ثم يُرفع العلم على القمّة عند «العزائم».
- قائمة مهام تُعلَّم بنودها، ثم أيقونة المشاركة.

| الملف | الاستخدام |
|---|---|
| `output/ahdaf-reel-voice.mp4` | **الفيديو النهائي مع الصوت** |
| `output/ahdaf-reel.mp4` | نفس الفيديو بدون صوت |
| `index.html` | المصدر الحي، يُولَّد من `tools/build.py` |
| `audio/voice-clean.m4a` | الصوت بعد التنظيف |
| `audio/voice-original.m4a` | التسجيل الأصلي |
| `reels/cover.png` | الغلاف |
| `reels/transcript.md` | النص على الشاشة وسجل تعديلات الصوت |

## إعادة البناء والتصدير
```bash
python3 tools/build.py
S=../../.claude/skills/carousel-to-reel/scripts
node $S/render.js . --audio audio/voice-clean.m4a
```

### تنظيف الصوت (للإعادة)
```bash
python3 $S/clean_voice.py audio/voice-original.m4a transcript.json audio --cut 93.95-96.82
```
