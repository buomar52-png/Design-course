# قرّة العين — القالب الليلي بدون مربعات · ٩:١٦ · ٤٢ ثانية

ريل عن مكانة الصلاة بالقالب الليلي بدون مربعات، بلا عنوان ولا ترقيم. الانتقال بين الشرائح **«مدّ ضوئي»**، وفي النهاية أيقونة المشاركة.

| الشريحة | التصميم |
|---|---|
| خليل الرحمن إبراهيم | الكعبة تحت سماء نجوم |
| ﴿رَبِّ اجْعَلْنِي مُقِيمَ الصَّلَاةِ…﴾ | هلال ونجوم + بطاقة الآية |
| مدح الله إسماعيل | شريحة نصّية |
| ﴿وَكَانَ يَأْمُرُ أَهْلَهُ بِالصَّلَاةِ…﴾ | بيت تضيء نوافذه وبابه واحدًا تلو الآخر، ثم هلال فوقه |
| مصدر فرحٍ وأُنسٍ وسرور | ثلاثة فوانيس، يضيء كلٌّ منها مع كلمته |
| «وَجُعِلَتْ قُرَّةُ عَيْنِي فِي الصَّلَاةِ» | عين تنفتح وفيها بريق |
| ليرتاح بها لا ليرتاح منها | شريحة نصّية: شارة مضيئة مقابل شارة باهتة مشطوبة |
| «يَا بِلَالُ، أَقِمِ الصَّلَاةَ، أَرِحْنَا بِهَا» | مئذنة يخرج منها الأذان موجات |
| صلاة الفجر هي البداية | شمس تشرق خلف مسجد |
| ﴿وَالَّذِينَ اهْتَدَوْا زَادَهُمْ هُدًى…﴾ | حلقات نور تزيد مع كل كلمة |

| الملف | الاستخدام |
|---|---|
| `output/salah-reel-voice.mp4` | **الفيديو النهائي مع الصوت** |
| `output/salah-reel.mp4` | بدون صوت |
| `index.html` | المصدر الحي، يُولَّد من `tools/build.py` |
| `audio/voice-clean.m4a` | الصوت بعد التنظيف |
| `audio/voice-original.m4a` | التسجيل الأساسي |
| `audio/voice-original-ending.m4a` | التسجيل الثاني (منه العبارة الأخيرة) |
| `reels/transcript.md` | النص على الشاشة وسجل تعديلات الصوت |

## إعادة البناء
```bash
python3 tools/build.py
S=../../.claude/skills/carousel-to-reel/scripts
# دمج: التسجيل الأساسي حتى 36.70 ث + 0.5 ث صمت + التسجيل الثاني من 0.20 إلى 7.80 ث → joined.wav
python3 $S/clean_voice.py joined.wav tools/transcript.json audio --protect 4.85-9.45 --protect 13.15-17.95 --protect 40.0-44.7
node $S/render.js . --audio audio/voice-clean.m4a
```
